更新说明 · 对话内 AI 生图（Agnes）
=====================================
版本：v1.2.0（versionCode 3）
日期：本次交付
适用：入卷 PWA / Android APK

一、这次加了什么
----------------
在对话里直接生成插画，不再需要离开 App 去别处画图。

1. 对话内 AI 配图
   - AI 会在剧情需要时自动配图（首次登场、场景切换、高潮、转折），
     图直接挂在当轮回复下方。
   - 输入框左侧新增圆形「生成配图」按钮，可随时手动生图。
   - 自动配图带「AI 配图」角标，手动生成的不带，一眼可区分。

2. 图片查看与操作
   - 点击图片进入全屏灯箱：左右箭头切换、底部缩略图条、下载、删除。
   - 键盘支持：ESC 关闭，← / → 切换。
   - 消息内多图自动排成网格；单图占满一行。
   - 生成过程显示「绘制中…」占位卡，失败显示原因（如 HTTP 429）。

3. 可编辑的生图提示词板块（设置 → 生图设置）
   - 「生图指令模板」：决定 AI 什么时候配图、用什么格式请求。
     留空即用内置默认模板，可整段改写，也可一键「恢复默认」。
   - 「生图提示词（手动）」：手动生图面板的预填内容。
   - 「默认风格后缀」：全局追加到每次生图的画面描述后。

4. 设置项
   - 启用生图功能 / 允许 AI 自动配图（两个独立开关）
   - API Key（留空则不生图，由你自己填）
   - 接口地址、生图模型
   - 默认尺寸（1K/2K/3K/4K）、默认比例（9 种）
   - 压缩最长边（512/640/768/1024）、JPEG 质量（0.6/0.72/0.85/0.92）
   - 每会话图片上限（8/16/24/40，超出自动淘汰最旧的）
   - 「测试生图接口」按钮：当场验证 Key 是否可用

二、技术要点
------------
- 图片以 base64 直接落盘到会话数据里，因此离线可看、导出不丢。
- 生图后按设定压缩（默认 768px / JPEG 0.72），实测 1.14MB 的
  1024×1024 原图压缩后约 17KB。
- 会话级数量上限，跨消息按时间淘汰最旧的图片。
- 未填 Key 时：按钮显示但提示去设置页，AI 也不会收到配图指令，
  不产生任何多余请求。
- 关闭生图功能时：入口按钮隐藏，注入的指令为空。

三、改动文件
------------
- 新增 agnes.js          —— Agnes 生图客户端、图片压缩、提示词模板与编排
- common.js              —— 新增 13 个生图设置默认项；MVU.cleanText 新增
                            image 块清理规则；Icons 新增 image / sparkle 图标
- chat.html              —— 生图按钮、生图面板、消息内图片卡、全屏灯箱，
                            以及 AI 回复落地后的自动配图挂点
- settings.html          —— 新增「生图设置」区块
- sw.js                 —— 缓存清单加入 agnes.js，缓存版本 v2 → v3
- android/app/build.gradle —— syncWebAssets 纳入 agnes.js；版本 1.1.0 → 1.2.0

四、注意事项
------------
1. 需要自备 Agnes API Key，在 设置 → 生图设置 里填入。
   不填则只保留手动入口但不发请求，AI 也不会自动配图。
2. 图片占用会话存储：默认上限 16 张 / 每会话。
   图多时建议把「压缩最长边」调到 640 或 512。
3. 生图耗时通常 10–30 秒，期间可继续读正文，不阻塞。
4. 老会话（无 images 字段）完全兼容，不会报错。
