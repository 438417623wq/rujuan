【入卷】v1.3.1 更新说明 —— 人物页修复 + 顶栏中文恢复

■ 修复问题
1. 人物页混入自身属性（本轮反馈）
   现象：人物页前几个条目显示「境界 / 生命值 / 灵力 / 灵石 / 声望」，
   同时顶部大标题有时变成「无名修士」。
   原因：AI 生成状态栏 schema 时，常把这类字段误标注 group:"人物"，
   分类逻辑「schema 显式声明优先」就把它们全送进了人物页。
   修复：增加防呆判定 —— 数字字段永远视为自身属性；
   纯文本字段若字段名命中强自身词（境界/修为/等级/生命/灵力/体力/理智/
   灵石/金钱/声望/经验/金币 及 realm/level/hp/mp/gold/exp 等），
   即使被误标「人物」也强制归入自身属性区。人物页现在只列真正的 NPC。

2. 顶部小栏目恢复中文
   现象：手机窄屏下顶栏只显示图标和数字，看不到「人物/储物/功法/任务/世界」。
   原因：旧版样式在 460px 以下隐藏了标签文字。
   修复：窄屏不再隐藏文字，改为整体缩小（字号 10.5px、图标 13px、
   计数 8.5px），五个中文栏目在任意宽度都完整可见。

■ 验证情况
· 五种数据形态探针全部通过（标准数组 / 对象布局 / 拼音名 / 字符串数组 / 分组误标）
· 分组误标场景修复后：人物页仅剩 NPC，Hero 标题恢复「筑基三层」
· 顶栏 DOM 断言：人物 3 / 储物 0 / 功法 0 / 任务 0 / 世界 1，中文可见
· 内联脚本语法检查 0 失败
