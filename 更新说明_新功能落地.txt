一、② @Depth 注入地基（④⑦⑧ 的公共前置）
--------------------------------------------------------------------------------

对标酒馆的 Author's Note：把一段内容插到 messages 的「倒数第 N 条之前」。
N=0 表示插在最末尾。

  PromptBuilder.collectAtDepthBlocks(conversation, worldBookBlocks)
    统一汇总所有需要 @Depth 的块，按固定顺序：
      世界书 at_depth 条目 → 面板文风块 → 骰子块 → 作者注/上帝指令
  PromptBuilder.applyAtDepth(msgs, { atDepth })
    一次性重建数组（不是 splice），避免逐条插入时的下标位移。

  世界书条目新增 position = at_depth，并带独立深度输入框。
  修掉一个老问题：_normalizePosition 之前会把 at_depth 归一到 after_input，
  等于「选了但没用」。

--------------------------------------------------------------------------------
二、③ 上帝编辑模式（作者注式）
--------------------------------------------------------------------------------

摘要面板里新增编辑区：
  writingNoteEnabled   开关
  writingNoteText      正文
  writingNoteDepth     深度 N（插到倒数第 N 条之前）
  writingNoteOneShot   只生效一轮（用完自动关）

  与「直接改正文」不同：作者注不污染对话历史，可随时改/随时撤。

--------------------------------------------------------------------------------
三、④ 记忆长度条 + 导出粘贴
--------------------------------------------------------------------------------

  Memory.getMemoryStats(conversation)  统计三层记忆的长度与占比
  Memory.estimateTokens(text)          CJK 1 字≈1 token，其余 4 字符≈1
  Memory.exportMemory(conversation)    导出成可读文本
  Memory.importMemory(conversation,txt) 粘贴导入（覆盖式写回）

  面板顶部新增 5 色分段长度条（ab / sm / ar / 正文 / 剩余预算），
  配 导出 / 粘贴导入 / 存进记忆库 / 从记忆库载入 四个按钮。

  导入后 lastMergedIdx 停在当前消息数，避免旧消息被重复压缩。

--------------------------------------------------------------------------------
四、⑤ 对话级预设 / 文风切换
--------------------------------------------------------------------------------

  优先级链：对话级预设 > 全局预设 > API 方案 > 内置默认
  PromptBuilder.getActivePreset(settings, conversation)
  conversation.presetId 为空 = 跟随全局。

  「更多」菜单新增「本对话预设」分组，可单对话切换文风/参数，不影响其他对话。

--------------------------------------------------------------------------------
五、⑥ 故事线容器 + 记忆库
--------------------------------------------------------------------------------

  故事线（Storyline）：把多个对话归到一条线下，新对话可继承设定。
    captureTemplate   从对话抓一份模板（深拷贝）
    create/rename/remove/conversations/buildConversation/refreshTemplate
    buildConversation 生成新对话时不继承消息与记忆（干净开局）
    首页新增故事线区：新建 / 改名 / 删除 / 用故事线开新对话 / 刷新模板
    对话卡片上可直接「加入故事线」

  记忆库（MemoryLibrary）：把一条对话的记忆存成可复用条目集合，套用到别的对话。
    capture(conversation, name) / applyTo(lib, conv, 'merge'|'replace') / remove
    merge 模式按 code 去重，不会重复塞同一条。

  ⚠ 踩坑：Storyline.remove 最初用 getConversation()（返回的是元数据索引）再
    saveConversation，会把对话内容写丢。改成 async + Storage.loadConversation()。

--------------------------------------------------------------------------------
六、⑦ 空白起步面板 + AI 改造面板
--------------------------------------------------------------------------------

  Panel 模块：world / characters / opening / style / rules 五栏。
    空面板不写入对话（panel: undefined），保持与老对话结构完全一致。
    Panel.toSettingText(conversation)  把面板拼成【故事设定】注入
    Panel.toStyleBlock(conversation)   把文风拼成 @Depth 块（depth 1）

  新建对话弹窗里加「起步面板」折叠区，可手填，也可点「AI 帮我改」
  （AI 改造走 Panel.buildAiRewriteMessages / parseAiRewrite）。
  对话内「更多」菜单 →「起步面板」可随时编辑。

--------------------------------------------------------------------------------
七、⑧ 骰子 / 硬核模式 + 快捷指令栏
--------------------------------------------------------------------------------

  Dice 模块：NdM[+K] 语法（1d20、2d6+1…），DEFAULT_SPECS = 1d20 / 1d100 / 1d6
    骰子结果作为 @Depth 块注入，让 AI 看得见这一轮的判定。
    硬核模式：AI 不能改写骰子结果（toggleHardcoreDice）。

  QuickReply 模块：输入区上方一条快捷指令栏
    默认四项：d20 / d100 / d6 / 继续
    type = dice（掷骰）或 insert（往输入框插文本）
    可增删改、可重置为默认。

八、配套的服务端与同步
--------------------------------------------------------------------------------

  server.py 新增 GET/PUT：
    /api/storylines
    /api/memoryLibraries
  （web 模式下新存储键必须服务端有端点才落盘；PUBLIC_MODE 下忽略写入。）

  Storage.syncFromServer() 现在也拉这两个键，并按 updatedAt 合并
  —— 本地更新的那条不会被远端旧数据覆盖掉。
  Storage.exportAll / importAll 也把这两个键带上了（导出备份不丢数据）。
