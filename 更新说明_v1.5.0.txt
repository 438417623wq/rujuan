入卷 v1.5.0 更新说明（UI 重构 · 生图 · 数据安全 · 同步修复）
日期：2026-10-11
================================================================================

本次是 1.3.3 之后的一次集中更新，覆盖四块：全新 UI 体系、对话内生图、
数据丢失类问题修复、服务端与安卓端写入安全。

--------------------------------------------------------------------------------
一、UI 全面重构（东方天工 3.0）
--------------------------------------------------------------------------------

1. 令牌化主题系统
   common.js 新增 Theme Manager，运行时注入 :root 令牌（背景/文字/金饰/
   圆角/阴影/缓动共 33 个），chat.html 不再硬编码颜色。多套意境主题可切换。
2. 首页重做
   - 紧凑古典 Hero 横幅 + 首屏统计（无故事时自动隐藏）
   - 悬浮灵动创作岛：次级图标钮 + 金色主行动钮，公网模式下自动收起导入导出
   - 故事线作为「主体」、对话作为「副本」分组渲染，副本带卷次序号
   - 旧存档未落 charCount 时按消息长度粗估，统计不再恒为 0
3. 设置页改四栏 Tab：接口 / 预设 / 生图 / 通用
4. 对话正文排版
   段落化渲染（按空行切块包 <p>），引号台词取消首行缩进，
   宣纸噪点装饰层（纯装饰、不拦事件）

二、对话内生图（agnes.js，新增文件）
--------------------------------------------------------------------------------

- 新模块 AgnesAPI / AgnesImage / AgnesPrompt / AgnesGen，独立于 common.js
- 国内站 / 国际站双站点，Key 与模型按站点独立记忆，切换站点自动带出
- 生图模型列表从 /models 拉取；支持 1K/2K/3K/4K 与多种画幅比例
- 图片挂在 msg.images 上：{ id, dataUrl, prompt, revised, ratio, size,
  source, ts, bytes }，source 区分 manual（面板）与 auto（AI 指令触发）
- 对话内图片卡片、灯箱（翻页/缩略图/下载/删除）、图片长廊视图
- 自动触发：AI 正文中出现生图指令时由 AgnesGen.processAutoRequests 接管
- 单对话图片数量上限、体积压缩与像素上限可在设置页配置

三、数据安全（本次最关键的修复）
--------------------------------------------------------------------------------

1. 同步不再吞掉本地正文（common.js syncFromServer）
   旧版在「服务端没有该对话」或 updatedAt 为 0/null 时跳过 push，却仍用
   服务端索引整份覆盖本地，本地唯一一份带 messages 的正文就此消失。
   现在：本地有正文而服务端没有/更旧时先保住本地，并把完整正文另存为
   本地兜底副本；服务端索引缺失的条目用本地备份补齐。
2. 导入导出显式失败
   - 旧版 `await fetch() || {}` 在 401/宕机时返回空对象，导出一个"看起来
     正常"的空备份还提示"数据已导出"——现在必须显式报错。
   - 备份里 conversations 为数组时不再被 Object.entries 变成 "0"/"1" 下标
     id（那会导致列表打开即"会话不存在"）。
   - 索引里有、正文读不出来 = 存档损坏，计入失败而不是当作导出成功。
   - 先写正文、成功后再登记索引，避免出现打不开的幽灵对话。
3. 服务器写入必须等结果
   旧版 fire-and-forget，settings.html 还会在 600ms 后 reload 取消在途请求，
   于是"导入成功"提示发出去了、服务器其实没收到。现在 importAll 等待确认。
4. 服务端原子写（server.py）
   - write_json 改为临时文件 + fsync + os.replace，每文件一把锁；
     旧实现就地截断，进程被杀会留半截 JSON，而 read_json 把损坏当"不存在"，
     对话就从列表和导出里静默消失。
   - read_json 额外吞 UnicodeDecodeError / OSError
   - 新增 safe_conv_id：校验存档 id，防目录穿越与非法文件名
   - 会话索引只写真实存在的字段，不再写入显式 null 冲掉本地好值
   - 索引 META_FIELDS 增加 storylineId / presetId
5. 安卓端原子写（AndroidBridge / NativeAiStreamStore）
   - saveData 改为临时文件 + fd.sync + rename，rename 失败退回原地拷贝
   - deleteData / loadData 失败时打日志，不再静默
   - 流状态文件新增 3 天终态保留期，服务结束时清理历史遗留文件

--------------------------------------------------------------------------------
四、记忆与 MVU 状态栏加固
--------------------------------------------------------------------------------

1. 记忆安全网：当前预设若没有任何"摘要格式"类条目（导入的写卡预设常缺），
   逐层摘要（ab→sm→ar）永远抓不到输入，体感就是"记忆没生效"。
   现在兜底补一条，保证记忆系统始终有输入。
2. 摘要块提取与状态栏同一套宽松围栏：容忍大小写/空格/未闭合/多块，
   语言前缀可选（json: / text: / 任意 lang:），不会误命中 mvu_init / mvu_update。
3. JSON 修复器：逐字符转义字符串内裸引号与裸换行、去尾逗号、
   中文智能引号转 ASCII、截取平衡括号子串。
4. patch 路径防御：AI 漏写 path 不再抛异常中断整批补丁（这是"状态栏不更新"
   的一种成因）；未初始化字段按 schema 默认值起算。
5. 显示名兜底：绝不把拼音 id 当最终显示名传给 UI。
6. 状态栏数值滚动动画、低值警示、字段 delta 徽标（+N / -N）。
